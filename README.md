# 📦 AssetFlow

> A cross-platform mobile application designed for efficient asset management, inventory tracking, and barcode scanning.

Developed as a **University / Personal Project**, AssetFlow allows users to scan, register, track, and manage physical assets easily from their devices.

---

## ✨ Features

* 📱 **Asset Management:** Add new assets with custom details (`NewAssetPage.xaml`).
* 📷 **Barcode / QR Scanner:** Integrated scanner functionality to identify assets quickly (`ScannerPage.xaml`).
* 📊 **Asset Overview:** View, search, and manage registered assets in a single interface (`MainPage.xaml`).
* 🔄 **Cross-Platform Support:** Built to run on Android, iOS, and Windows platforms.

---

## 🛠️ Tech Stack

* **Framework:** [.NET MAUI / Xamarin] *(velg den du bruker)*
* **Language:** C# & XAML
* **Platform:** Cross-platform (Android, iOS, Windows)
